# AIインタビューシステム仕様書

## 大規模証言リサーチプラットフォーム

Version: 1.0
Purpose: 社会問題調査のための体験証言収集システム

---

# 1. システム概要

本システムは、AIインタビューを通じて個人の体験や証言を収集し、
**公正なリサーチレポートを作成するための基礎データを生成するプラットフォーム**である。

従来の

* アンケート（情報量不足）
* 人間インタビュー（スケール不可）

の課題を解決し、

**インタビュー品質 × 大規模データ収集**

を実現する。

---

# 2. 想定ユースケース

初期テーマ

* オンライン詐欺被害の実態調査

将来拡張

* ハラスメント調査
* 災害体験
* 医療アクセス
* 行政サービス
* 社会問題の体験調査
* 政策評価

# 3. ユーザー

## 3.1 回答者

* ITリテラシーが様々
* 長文入力をしない可能性あり
* 音声入力を使う可能性あり

---

## 3.2 リサーチャー

利用目的

# 4. システムコンセプト

回答者は

**自由に体験を話す**

AIは

* 情報抽出
* 不足情報検出
* 深掘り質問

を行い、

**一定のデータ品質に到達するまでインタビューを続ける。**


# 12. AIインタビュー機能

AIの役割

---

## 12.1 情報抽出

回答から以下を抽出

* 出来事
* 人物
* 時間
* 行動
* 感情
* 被害

---

## 12.2 不足情報検出

リサーチ項目と比較し

不足情報を検出。

例

ユーザー回答

> SNSで投資の話をされた

不足情報

* SNS種類
* 相手の身分
* 投資対象
* 被害額
* 時系列

---

## 12.3 深掘り質問生成

不足情報に対する質問

例

* そのSNSは何でしたか？
* 相手はどんな人を名乗っていましたか？
* 実際に送金した金額はありますか？

---

# 14. データ品質評価

証言の品質をスコア化する。

評価項目

* 必須項目充足率
* 具体性
* 時系列
* 曖昧度
* 整合性

---

## Completeness Score

```
0.0 – 0.4 情報不足
0.4 – 0.7 追加質問必要
0.7 – 0.85 分析可能
0.85以上 高品質データ
```

# 17. 公正性設計

AIは

**特定の結論に誘導しない。**

禁止

* 誘導質問
* 仮説誘導
* 推測断定

例

NG

「それは詐欺だと思いましたか？」

OK

「その時どのように感じましたか？」
